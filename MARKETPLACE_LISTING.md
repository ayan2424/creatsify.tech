# Creatsify Studio - High-Performance PHP MVC Agency & Software Studio CMS

**Creatsify Studio** is a commercial-grade, zero-framework PHP 8.2+ MVC portfolio and agency platform designed for software agencies, freelance architects, and SaaS creators.

Featuring an ultra-clean **Linear / Dark Luxury** aesthetic, an interactive **Cheetah-style Live Chat Desk**, automated **Meta WhatsApp Cloud API (v21.0)** notifications, a multi-gateway **SMS Inbox**, a Cheezify-style **Homepage Section Builder**, and a **1-Click Web Installer**.

---

## 🌟 Key Highlights & Architectural Features

- **Zero-Framework PHP 8.2+ MVC Engine:** Lightning-fast response times under 25ms. No heavy vendor dependencies, runs effortlessly on standard cPanel, VPS, or shared hosting.
- **Cheetah-Style Live Chat Desk:** First-party local rule engine with context crawling, intelligent intent matching, human agent handoff, audible chimes, and instant notification alerts.
- **Two-Way Meta WhatsApp Cloud API (v21.0):** Clean E.164 normalization for international and Pakistani phone numbers (`03xx` &rarr; `923xx`), incoming webhook receiver, and real-time thread messaging.
- **Two-Way Multi-Gateway SMS Inbox:** Supports Twilio REST API and local Pakistani SMS aggregators.
- **Multi-Channel Notification Dispatcher:** Dispatches new client inquiries simultaneously via WhatsApp, SMS, SMTP Email, and in-app bell counters.
- **Homepage Section Builder (Cheezify Architecture):** Edit hero rotating headlines, stats counters, Cheetah shipment tracking simulation, founder highlights, and marquees in real time.
- **Portfolio & Case Study CMS:** Dynamic categorization (SaaS & Platforms, Stores & Ordering, Apps & Tools) with tech stack pills and live external links.
- **Media Library & Asset Manager:** Drag-and-drop uploader with 1-click **Copy Image URL** to clipboard.
- **User & Role Management (Cheezify Security):** Super Admin, Admin, and Editor roles with an immutable **Audit Log** tracking all administrative operations.
- **Visual Theme Customizer:** Live primary accent color picker with real-time site synchronization and Dark / Light theme toggle.
- **Custom Code & CSS Injectors:** Safely inject Google Analytics, Meta Pixel, header scripts, and custom stylesheet rules directly from the admin desk.
- **1-Click Web Installer (`install.php`):** 4-step graphical setup wizard with server pre-flight checks, automatic schema migration, and installer locking.

## 🛠️ Technology Stack

- **Backend:** Pure PHP 8.2+ (Clean Object-Oriented MVC Architecture)
- **Database:** MySQL 5.7+ / MariaDB 10.3+ / SQLite 3
- **Frontend:** Vanilla ES6 JavaScript, CSS3 Custom Properties, Google Fonts (*Bricolage Grotesque* & *DM Sans*)
- **Integrations:** Meta WhatsApp Cloud API v21.0, Twilio SMS API, Raw Socket SMTP Client
